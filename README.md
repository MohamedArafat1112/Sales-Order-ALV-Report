# SAP ABAP - Sales Order ALV Report

## Project Overview
This project is a classical SAP ABAP ALV Report
that displays Sales Order Header and Item Data.

## SAP Tables
- VBAK: Sales Document Header
- VBAP: Sales Document Item

## Technologies & Concepts
- ABAP Programming
- Open SQL
- Internal Tables
- Work Areas
- SELECT-OPTIONS
- FOR ALL ENTRIES
- Internal Table Processing
- ALV Grid Display
- Field Catalog
- ALV Sorting
- ALV Filtering
- Custom PF-STATUS
- ALV Top of Page
- REUSE_ALV_GRID_DISPLAY
